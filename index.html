What is EcoTextile?

A digital operating layer for textile teams.

EcoTextile is designed to replace scattered operational information with a more understandable workspace. Employees can work with structured records while supervisors can review activity, batches, inventory and reports from one environment.

EcoTextile User Manual

From first login to advanced administration.

This quick manual is designed as an organization-friendly introduction. Your installed software version and company configuration may contain additional or different screens.

1. Beginner — Start Here

  • Open the EcoTextile address supplied by your organization.
  • Sign in using your authorized company credentials.
  • Start from the Dashboard to understand the current operational overview.
  • Use the main navigation to locate Products/Materials, Production, Batches, Inventory, Scanner and Reports.
  • Always save a record before moving to the next operational step.

2. Intermediate — Daily Operations

  • Review or create the relevant product/material record.
  • Create or update the production activity.
  • Use a clear batch/reference number for traceability.
  • Review related inventory information.
  • Use supported scanning workflows where appropriate.
  • Use reports to review operational information and prepare internal outputs.

3. Advanced — Supervisor / Administrator

  • Review user access and application security controls.
  • Check audit/security information where available.
  • Troubleshoot scanner and camera permissions.
  • For LAN deployments, verify that the service is running and devices are connected to the approved network.
  • Maintain operational backups according to the organization's IT procedure.

4. Scanner Quick Guide

  • Make sure the code is visible and readable.
  • For a hardware scanner, verify the connection.
  • For mobile camera scanning, allow camera permission.
  • If the item is not recognized, confirm that its record exists and the correct code/reference is being used.

5. Reporting an Issue

Tell support: what you were trying to do + which module + what happened + what you expected. Include the exact error message or screenshot if possible. Never send passwords.

6. Organization Workflow

Set up → Record → Batch → Track → Review → Report
